# Hello World

Skill template minimal untuk repo `dimsdeall/my-skills`.

## Overview

Ini skill contoh — ganti isi ini dengan workflow Kak Dimas sendiri.

## Workflow

1. **Check** — cek apakah skill ter-load (`skill hello-world` kebaca).
2. **Greet** — sapa user dengan bahasa Indonesia sopan.
3. **Confirm** — konfirmasi instalasi berhasil: `npx skills add dimsdeall/my-skills --skill hello-world` OK.

## Usage

```bash
npx skills add dimsdeall/my-skills --skill hello-world
npx skills add dimsdeall/my-skills --skill hello-world --list
```

Edit file ini (`skills/hello-world/SKILL.md`) lalu push — user lain akan dapat update via `npx skills update`.
